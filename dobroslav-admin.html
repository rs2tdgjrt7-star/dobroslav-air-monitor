Для доступу введіть секретний токен ADMIN_TOKEN, налаштований у Cloudflare Worker.

Токен зберігається лише в пам’яті цієї відкритої вкладки. Не вставляйте його в HTML-код, не публікуйте на GitHub і не надсилайте в чат.
